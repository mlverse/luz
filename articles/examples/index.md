# Examples

This gallery of examples uses luz to train and validate a range of
common deep learning architectures. The gallery also demonstrates basic
and advanced usage of luz.

##### CharGPT

intermediate

Train a character-level GPT-2 on Shakespeare texts.

[See code](https://mlverse.github.io/luz/articles/examples/chargpt.md)

##### Binary classification

basic

Demonstrates using pre-trained models to build a binary classification
model.

[See
code](https://mlverse.github.io/luz/articles/examples/dogs-vs-cats-binary-classification.md)

##### Autoencoder

basic

Builds an autoencoder for the MNIST dataset. Demonstrates overwriting
the predict method

[See
code](https://mlverse.github.io/luz/articles/examples/mnist-autoencoder.md)

##### Virtual batch size

advanced

Showcases how to create a custom fully customized training step

[See
code](https://mlverse.github.io/luz/articles/examples/mnist-cnn-virtual-batch-size.md)

##### Simple CNN

basic

Trains an AlexNet-like CNN to classify digits of the MNIST dataset

[See code](https://mlverse.github.io/luz/articles/examples/mnist-cnn.md)

##### DCGAN

intermediate

Deep Convolutional Generative Adversarial Network to generate images.

[See
code](https://mlverse.github.io/luz/articles/examples/mnist-dcgan.md)

##### MixUp augmentation

intermediate

Demonstrates using the MixUp callback

[See
code](https://mlverse.github.io/luz/articles/examples/mnist-mixup.md)

##### Triplet loss

intermediate

Train an embedding model to minimized the triplet loss.

[See
code](https://mlverse.github.io/luz/articles/examples/mnist-triplet.md)

##### Variational Autoencoder

intermediate

Trains a variational autoencoder on MNIST and explores its latent space.

[See code](https://mlverse.github.io/luz/articles/examples/mnist-vae.md)

##### UNET implementation

intermediate

Implements a UNET model to separate the background of images of cats and
dogs.

[See code](https://mlverse.github.io/luz/articles/examples/pets-unet.md)

##### Text classification from scratch

basic

Implements text classification from scratch.

[See
code](https://mlverse.github.io/luz/articles/examples/text-classification.md)

##### Training a causal language model from scratch

advanced

Implements datasets and trains a causal language model from scratch
using R source code.

[See
code](https://mlverse.github.io/luz/articles/examples/text-generation.md)
