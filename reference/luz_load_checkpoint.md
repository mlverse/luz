# Loads a checkpoint

Works with checkpoints created typically with
[`luz_callback_model_checkpoint()`](https://mlverse.github.io/luz/reference/luz_callback_model_checkpoint.md).

## Usage

``` r
luz_load_checkpoint(obj, path, ...)
```

## Arguments

- obj:

  Object to which we want to load the checkpoint.

- path:

  Path of the checkpoint on disk.

- ...:

  unused. Is there to allow future extensions.
